# Code of Conduct

## Our Commitment

ProtonVPN-Next is committed to providing a welcoming and inclusive environment for all contributors, users, and community members, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, sexual identity and orientation, or socioeconomic status.

We are dedicated to fostering a community built on respect, privacy, security, and technical excellence. As a privacy-focused VPN project, we hold ourselves to the highest standards of integrity and transparency.

## Our Values

### 1. **Privacy First**
- We respect the privacy of all community members
- We do not collect or share personal data without explicit consent
- All contributions are evaluated fairly, not based on personal information
- Discussions remain confidential unless explicitly made public

### 2. **Security & Trust**
- We take security vulnerabilities seriously and handle them responsibly
- All community members should feel safe contributing and reporting issues
- We maintain transparency about project security practices
- Malicious intent or attempts to compromise the project will not be tolerated

### 3. **Inclusivity & Respect**
- We welcome contributors of all skill levels
- We respect diverse perspectives and backgrounds
- We create an environment free from discrimination and harassment
- We encourage mentorship and knowledge sharing

### 4. **Technical Excellence**
- We value code quality, performance, and security
- Constructive feedback is given and received with openness
- We celebrate innovation while maintaining stability
- Peer review is about improving the project, not personal criticism

## Expected Behavior

### As a Contributor:
- **Be Respectful**: Treat all community members with courtesy and professionalism
- **Communicate Clearly**: Be concise and constructive in issues, PRs, and discussions
- **Test Your Work**: Ensure code changes are tested and don't break existing functionality
- **Document Changes**: Provide clear commit messages and PR descriptions
- **Respect Architecture**: Follow the Clean Architecture / MVVM patterns and coding guidelines
- **Honor Privacy**: Never add telemetry or tracking to the `privacy` build flavor
- **Report Issues Properly**: Use bug report templates and provide sufficient context
- **Give Credit**: Acknowledge the work of others and cite sources

### As a Maintainer:
- **Respond Timely**: Address issues and PRs within a reasonable timeframe
- **Provide Feedback**: Give constructive reviews and guidance
- **Be Fair**: Apply rules consistently to all contributors
- **Communicate**: Explain decisions transparently, especially for rejections
- **Support Growth**: Help contributors improve their skills and understanding
- **Maintain Security**: Protect the project's integrity and user safety

## Unacceptable Behavior

We do not tolerate:
- **Harassment**: Any form of intimidation, bullying, or targeting
- **Discrimination**: Based on any protected characteristic or background
- **Abuse**: Verbal, sexual, or any form of aggressive behavior
- **Hate Speech**: Slurs, derogatory language, or attacks on groups
- **Spam**: Unsolicited commercial content or flooding
- **Malicious Activity**: Attempts to compromise security, inject malware, or sabotage
- **Privacy Violations**: Sharing others' personal information without consent
- **Off-Topic Disruption**: Using project channels for unrelated political or commercial purposes

## Scope

This Code of Conduct applies to:
- GitHub issues, pull requests, and discussions
- Project documentation and comments
- Community chat channels and forums
- Virtual and in-person events organized by the project
- Public interactions referencing the project

This Code of Conduct does **not** apply to:
- Private conversations unrelated to the project
- Conduct on other platforms unless it directly harms the community

## Reporting & Enforcement

### How to Report
If you experience or witness unacceptable behavior:

1. **For Security Issues**: Email security concerns directly to maintainers (see SECURITY.md)
2. **For Conduct Issues**: Report to project maintainers with:
   - Description of the incident
   - Relevant links or context
   - Any evidence (screenshots, logs)
   - Your preferred contact method

### Consequences
Depending on severity, responses may include:
1. **Verbal Warning**: Explanation of why behavior violates the Code of Conduct
2. **Temporary Suspension**: Loss of contribution/commenting privileges for a set period
3. **Permanent Ban**: Removal from the project for serious or repeated violations

All reports are taken seriously and will be handled confidentially. Reporters will not face retaliation.

## Appeals Process

If you believe enforcement action was unjust:
1. Submit a written appeal to project maintainers
2. Clearly explain why you believe the decision was incorrect
3. Provide any additional context or evidence
4. Await response (typically within 7 days)
